# 胃癌知识库领域指南

## 概述

本知识库收录胃癌相关的结构化医学知识，涵盖流行病学、分子分型、临床指南和治疗方案等领域。

## 知识域说明

### 1. 流行病学 (Epidemiology)

胃癌流行病学数据，包括发病率、死亡率、危险因素等。

**数据来源**：
- 国家癌症中心数据
- GLOBOCAN全球癌症统计
- WHO/IARC报告

**主要内容**：
- 中国2022年新发病例35.87万
- 死亡人数约26万
- 主要危险因素：幽门螺杆菌感染、腌制食品、吸烟
- 高发地区：西北和东北地区

### 2. 分子分型 (Molecular Subtyping)

胃癌的分子分类和生物标志物检测。

**数据来源**：
- TCGA研究
- Lauren分型
- 临床生物标志物检测

**主要内容**：
- Lauren分型：肠型、弥漫型、混合型
- HER2阳性率：7-34%
- MSI-H/dMMR阳性率：5-10%
- EBV阳性率：8%
- PD-L1 CPS评分

### 3. CSCO指南 (Clinical Guidelines)

中国临床肿瘤学会(CSCO)指南推荐。

**数据来源**：
- CSCO胃癌诊疗指南2024
- ToGA研究、RAINBOW研究等临床试验

**主要内容**：
- 早期胃癌内镜下切除适应证
- 进展期胃癌D2根治术
- 晚期胃癌一线/二线/三线治疗
- 免疫治疗适应证

### 4. 治疗 (Treatment)

胃癌治疗方案和药物信息。

**数据来源**：
- CSCO指南
- 临床研究数据

**主要内容**：
- 手术：胃癌D2根治术
- 化疗：SOX、XELOX、DOS方案
- 靶向：曲妥珠单抗、雷莫芦单抗、阿帕替尼
- 免疫：PD-1抑制剂
